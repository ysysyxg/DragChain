# DragChain

工业拖链（电缆链）动画 Actor 插件，用于 Unreal Engine 中的原理动画与产线演示。

样条路径 + 链长守恒运动学驱动，头/中/尾三段模型可选，所有关键参数均可由 Sequencer 属性轨道 K 帧驱动，不依赖物理仿真。

![Category](https://img.shields.io/badge/UE-5.6%20%7C%205.8-blue) ![Type](https://img.shields.io/badge/type-Runtime%20Plugin-lightgrey)

## 特性

- **链长守恒运动学**：弯心位置按 `x_b = (L + X - PI*R) / 2` 解析求解，拖动带动对象时链条自然折叠/展开，不出现拉伸变形。
- **三段式模型**：头节（HeadLink）、中间节（MidLink）、尾节（TailLink）可使用不同 StaticMesh；关闭后回退为单节重复排列。
- **双向挂接**：
  - 固定父级 + 偏移：整条链随固定父级运动/旋转。
  - 带动对象 + 末端对齐偏移：由外部 Actor（车架、滑台）驱动末端位置。
- **Sequencer 友好**：核心参数带 `Interp`，可直接在属性轨道上打关键帧；插件在运行时叠加偏移，不写回属性，避免与 K 帧互相覆盖。
- **无状态求解**：末端位置完全基于当前帧计算，不依赖增量基准，保证 Movie Render Queue 逐帧渲染与视口预览一致。
- **预设系统**：常用总长度预设（0.6 m ~ 26 m）与可复用的整链参数快照（节数/节距/弯曲半径/车架位置…）。
- **编辑器工具**：一键重设模型枢轴到几何中心、自动附加到固定父级。

| 项 | 版本 |
|---|---|
| Unreal Engine | 5.6 / 5.8（本仓库源码在 5.8 下验证） |
| 模块类型 | Runtime |
| 依赖模块 | Core, CoreUObject, Engine, MeshDescription, StaticMeshDescription |

## 安装

1. 将 `DragChain` 整个目录复制到工程的 `Plugins/` 下（或引擎的 `Engine/Plugins/Marketplace/` 下）。
2. 重新生成工程文件并编译：
   ```
   UnrealBuildTool / Build.bat <Project>Editor Win64 Development -NoLiveCoding
   ```
   > 建议先关闭编辑器。Live Coding 会锁定已加载的 DLL，导致重编译后仍运行旧逻辑。
3. 启动编辑器，在 **放置 Actor** 面板搜索「拖链Actor」。

## 参数说明

参数按细节面板分类组织：

### 拖链 | 参数
| 参数 | 说明 |
|---|---|
| 节数 | 链节数量（≥2），与节距共同决定总长度 |
| 总长度 | 拖链展开总长度（cm），由节数 × 节距推算 |
| 节距 | 单个链节长度（cm） |
| 弯曲半径 | 拖链回转弯半径（cm），影响弯心位置与圆弧采样 |
| 车架位置 | 运动端当前位置，可由 Sequencer 直接驱动 |
| 固定端位置 | 拖链固定端的世界坐标 |
| 走向方向 | 拖链展开方向 |
| 整体翻转 | 整体镜像，用于反向布置 |

### 拖链 | 模型
| 参数 | 说明 |
|---|---|
| 头节 / 中间节 / 尾节模型 | 三段 StaticMesh，可分别指定 |
| 启用头尾模型 | 关闭后整链使用中间节模型 |
| 圆弧采样数 | 弯曲段的插值密度（8–64），影响曲线平滑度 |
| 链节/头节/尾节缩放 | 独立缩放，用于适配不同规格链节 |
| 链节偏航/俯仰/滚转 | 单节模型的姿态微调 |
| 自动枢轴匹配 | 按 Mesh 包围盒自动校正放置枢轴 |
| 头节/尾节翻转、位置偏移 | 端节朝向与位置修正 |

### 拖链 | 挂接
| 参数 | 说明 |
|---|---|
| 固定父级 | 拖链固定端所依附的 Actor |
| 固定父级偏移 / 跟随固定父级旋转 | 相对父级的位置与旋转继承 |
| 带动对象 | 驱动拖链运动端的外部 Actor |
| 拖链末端对齐偏移 | 末端相对带动对象的位置修正 |
| 带动对象驱动车架 | 由带动对象 Transform 反推车架位置 |
| 链条平移贴合带动对象 | 保持链条与带动对象的贴合平移 |

### 拖链 | 预设 / 工具
- **总长度预设**：0.6 / 0.8 / 1.3 / 2.5 / 3 / 3.2 / 4 / 6 / 8 / 10 / 12 / 13 / 14 / 26 米。
- **预设列表 / 预设序号**：保存与切换整链参数快照。
- **重设模型枢轴到几何中心**：修正外部导入模型枢轴偏移。
- **自动附加到固定父级**：按当前参数完成 Attach。

## 运动学说明

```
弯心位置  x_b = (L + X - PI * R) / 2
```

- `L`：拖链总长度，`X`：运动端位移，`R`：弯曲半径。
- 上段长度 = `x_b`，下段长度 = `L - x_b - PI * R`，两段由半径 `R` 的半圆弧连接。
- 求解只依赖当前帧输入，无累积状态，因此可安全用于逐帧渲染。

## 设计约束

- 插件不写回 Sequencer 拥有的属性；偏移量在运行时叠加，属性归属保持单一。
- 固定父级的 `Mobility` 需为 Movable（或其父链为 Movable），Static 父级无法驱动子物体跟随。
- 插件自带「固定父级」逻辑与 UE 原生 Attach 互斥：使用原生 Attach 时，插件挂接参数不生效。
